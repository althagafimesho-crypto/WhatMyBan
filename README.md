# موقع What My Ban؟

موقع ثابت (HTML/CSS بس، بدون أي سيرفر أو قاعدة بيانات) — آمن تمامًا للنشر على مستودع GitHub عام لأنه ما فيه أي بيانات حساسة أو نماذج تسجيل.

## قبل النشر: بدّل الروابط

فيه رابطين لازم تبدلهم بالروابط الحقيقية تبعك، يتكررون بكل صفحة (index.html / privacy.html / terms.html):

1. **رابط إضافة البوت** — دور على `YOUR_CLIENT_ID` وبدّله بآيدي تطبيق البوت الحقيقي (نفسه اللي استخدمته بخطوة دعوة البوت لسيرفرك).
2. **رابط سيرفر الدعم** — دور على `YOUR_INVITE_CODE` وبدّله برمز دعوة سيرفرك (مثال: `https://discord.gg/abc123`).

أسهل طريقة تبدلهم: افتح مجلد الموقع بأي محرر (زي VS Code)، اضغط "Find & Replace across files" (Ctrl+Shift+H)، ودور عن `YOUR_CLIENT_ID` و `YOUR_INVITE_CODE` وبدلهم بضغطة وحدة.

## النشر على GitHub Pages

1. سوّي مستودع (Repository) جديد بحسابك على GitHub.
2. ارفع كل ملفات هذا المجلد للمستودع (index.html, privacy.html, terms.html, مجلد css, مجلد js).
3. روح لإعدادات المستودع: **Settings → Pages**.
4. تحت **Source** اختر **Deploy from a branch**، وحدد البرانش `main` والمجلد `/ (root)`.
5. احفظ، وانتظر دقيقة أو دقيقتين — بيطلع لك رابط الموقع فوق زي:
   `https://username.github.io/repo-name/`

كل مرة تحدث أي ملف وترفعه (push) للمستودع، الموقع يتحدث تلقائيًا خلال دقيقة تقريبًا.

## هيكلة الملفات

```
whatmyban-site/
  index.html      # الصفحة الرئيسية
  privacy.html    # سياسة الخصوصية
  terms.html      # شروط الاستخدام
  css/style.css   # كل التصميم بملف وحد
  js/main.js      # بس لفتح/قفل قائمة الجوال - ما فيه أي تتبع
```

## ملاحظة عن التطوير المستقبلي (Dashboard)

لما توصل لمرحلة الـ Dashboard اللي فيها تسجيل دخول (إيميل/باسورد)، **لازم** يكون الجزء اللي يتعامل مع البيانات الحساسة على سيرفر خلفي (Backend) منفصل ومتغيرات البيئة (زي التوكن وسر قاعدة البيانات) محفوظة بمكان مو داخل الكود المرفوع لـ GitHub (نفس فكرة ملف `.env` اللي استخدمناه بالبوت). الموقع الثابت هذا يقدر يبقى زي ما هو ويتحول لبس "الواجهة الأمامية" اللي تتكلم مع ذاك السيرفر، بدون ما تحتاج تغير أي شي بالتصميم الحالي.
